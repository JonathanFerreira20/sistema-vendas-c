Sistema de Vendas em C 💻📊

O Sistema de Vendas em C é um projeto desenvolvido com a linguagem C, focado no gerenciamento de produtos, controle de estoque e registro de vendas. O sistema foi criado com o objetivo de praticar lógica de programação, estruturas de dados e manipulação de informações utilizando conceitos fundamentais da linguagem C.

O projeto oferece uma solução simples e eficiente para controle de vendas, permitindo acompanhar produtos cadastrados, movimentação do estoque e desempenho dos itens mais vendidos.

🚀 Funcionalidades
✅ Cadastro de produtos
✅ Controle de estoque
✅ Registro de vendas
✅ Histórico de vendas
✅ Ranking de produtos mais vendidos
✅ Atualização automática do estoque após vendas
✅ Sistema organizado em menus interativos
🛠️ Tecnologias Utilizadas
Linguagem C
Estruturas (struct)
Laços de repetição (for, while)
Condicionais (if)
Vetores e manipulação de dados
🎯 Objetivo do Projeto

O objetivo deste projeto é desenvolver habilidades em programação estruturada utilizando a linguagem C, aplicando conceitos de lógica, controle de fluxo e manipulação de dados em um sistema funcional de gerenciamento de vendas.

Durante o desenvolvimento deste projeto foram trabalhados conceitos como:

Programação estruturada
Manipulação de estruturas em C
Controle de estoque e vendas
Organização de menus interativos
Lógica de programação
Manipulação de arrays e dados
